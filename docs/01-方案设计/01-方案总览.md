## 1. 方案摘要

本方案面向一个由作者独立维护、全球公开访问的个人博客，目标是在尽量低成本的条件下，实现文章管理、图片管理、公开展示、后台写作和后续扩展。

最终采用 **Cloudflare 单厂商架构**：前端、后端、数据库、图片存储和公开访问地址均由 Cloudflare 承载。前台使用 Astro，后端使用 Rust 编写并编译为 WebAssembly 运行在 Cloudflare Workers 上，文章数据存入 D1，图片和附件存入 R2。

在免费额度内，目标成本为 0 元／年；但 R2、Zero Trust 等产品开通时可能要求绑定支付方式，超额会自动计费，0 元是额度目标而非账单保证。预留的 50 元／年预算不强制使用，可作为未来域名或扩容费用。

### 核心决策

| 项目 | 决策 | 原因 |
|-|-|-|
| 云厂商 | 仅使用 Cloudflare | 减少账号、计费、权限和运维复杂度 |
| 前端 | Astro + TypeScript | 适合内容网站，SEO 友好，浏览器端 JavaScript 较少 |
| 后端 | Rust + workers-rs | 满足 Rust 技术实践，提供类型安全的 API |
| 后端运行方式 | Rust 编译为 WebAssembly | 适配 Cloudflare Workers，无需传统服务器 |
| 数据库 | Cloudflare D1 | 与 Workers 原生集成，个人博客容量充足 |
| 图片存储 | Cloudflare R2 | 免费容量较大，避免图片占用数据库 |
| 访问地址 | 免费 workers.dev | 无需购买和维护自定义域名 |
| 第一版评论系统 | 不实现 | 降低垃圾评论、审核和安全复杂度 |
| 第一版部署成本 | 免费额度内运行 | 符合低成本目标 |

## 2. 目标与边界

### 2.1 建设目标

- 公开展示文章、标签、归档和个人介绍。
- 支持在线撰写、编辑、预览、发布和撤回文章。
- 支持上传文章封面和正文图片。
- 使用 Markdown 作为文章源格式。
- 支持手机、平板和桌面浏览器。
- 支持 RSS、站点地图和基础 SEO。
- 保持较低的运维成本，并允许后续迁移数据库或绑定自定义域名。

### 2.2 第一版不实现的功能

- 多作者和复杂权限体系。
- 公开注册与用户中心。
- 评论、点赞和实时通知。
- 全文搜索引擎服务。
- 视频转码和复杂图片处理。
- 付费内容、电商和商业化功能。
- 自定义域名和中国大陆访问优化。

### 2.3 默认假设

- 只有一名管理员，即博客作者本人。
- 文章以中文为主，同时支持英文内容。
- 博客以个人非商业用途为主，访问量处于个人网站常见水平。
- 单张上传图片限制为 5 MB，文章正文不直接保存图片二进制数据。
- 全球公开访问不等同于保证所有国家和地区的访问速度与稳定性。
