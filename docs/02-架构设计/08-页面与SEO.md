# 页面、SEO 与可访问性

> 文档集索引：[index.toml](../index.toml) · 来源：飞书《个人博客技术方案》v1.1（2026-10-28）

## 11. 前台与后台页面

### 11.1 公开页面

- 首页：网站介绍、最新文章和精选文章。
- 文章详情：标题、日期、正文、标签和上下篇导航。
- 标签页：标签列表及对应文章。
- 归档页：按年份和月份组织文章。
- 关于页：个人介绍和联系方式。
- RSS、站点地图、404 页面。
- 深色模式和移动端导航。

### 11.2 管理页面

- 仪表盘：文章数量、草稿数量、图片占用估算。
- 文章列表：状态筛选、搜索、编辑和归档。
- 文章编辑器：Markdown、预览、标签、封面和发布设置；预览必须调用服务端同一渲染器，支持 localStorage 草稿自动保存和离开提醒。
- 图片管理：上传、复制地址、查看引用和删除；删除前显示引用位置，未引用对象延迟清理。
- 网站设置：标题、简介、作者信息和社交链接。

## 12. SEO 与可访问性

- 每篇文章拥有唯一、稳定且可读的 slug。
- 输出页面 title、description、canonical URL 和 Open Graph 信息。
- 自动生成 RSS 和 sitemap.xml；sitemap 排除草稿和归档文章，并输出 lastmod。
- 使用语义化 HTML 和正确的标题层级。
- 图片提供有意义的替代文本。
- 保证键盘操作、焦点状态和明暗主题对比度。
- 第一版 slug 发布后不可修改；如必须修改，先实现 redirects 表并写入 301，再开放修改，避免已有链接失效。
- 文章页输出 JSON-LD BlogPosting 结构化数据，封面图作为 og:image。
