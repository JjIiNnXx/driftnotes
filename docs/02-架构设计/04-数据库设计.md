# 数据库设计

> 文档集索引：[index.toml](../index.toml) · 来源：飞书《个人博客技术方案》v1.1（2026-10-28）

## 6. 数据库设计

### 6.1 表关系

```Plaintext
posts ──< post_tags >── tags
  │
  └── 使用 assets.cover 等图片地址引用 R2 中的资源

assets 独立保存上传文件信息
settings 保存键值型网站设置
```

### 6.2 posts：文章表

| 字段 | 类型 | 说明 |
|-|-|-|
| id | TEXT | 主键，使用 UUID |
| slug | TEXT | 唯一文章路径，只使用安全字符 |
| title | TEXT | 标题 |
| summary | TEXT | 摘要 |
| content_markdown | TEXT | Markdown 正文 |
| cover_asset_id | TEXT | 可选封面图片，关联 assets |
| status | TEXT | draft、published、archived |
| published_at | TEXT | 发布时间，ISO 8601 |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

**建议补充字段与限制：**增加 `content_html`（发布时渲染并净化后的 HTML，公开页直接使用）和 `version`（乐观锁，更新时校验，冲突返回 409）。正文 Markdown 限制在 80 KB 以内，并建议把 `content_html` 放独立表或 R2、分两条语句写入，避免 Markdown 与 HTML 合计超过 D1 单条 SQL 100 KB 的语句上限；超长文章应拆分。已发布文章的 `slug` 第一版禁止修改。

约束与索引：

- `slug` 唯一且非空。
- `status` 使用 CHECK 限制取值。
- 为 `status + published_at` 建索引，支撑公开文章列表。
- 为 `updated_at` 建索引，方便后台按最近编辑排序。

### 6.3 tags：标签表

| 字段 | 类型 | 说明 |
|-|-|-|
| id | TEXT | 主键 |
| name | TEXT | 唯一标签名称 |
| slug | TEXT | 唯一标签路径 |
| created_at | TEXT | 创建时间 |

### 6.4 post_tags：文章标签关系表

| 字段 | 类型 | 说明 |
|-|-|-|
| post_id | TEXT | 文章 ID |
| tag_id | TEXT | 标签 ID |

使用 `(post_id, tag_id)` 作为联合主键，并额外建立 `(tag_id, post_id)` 索引；否则按标签查文章会全表扫描。外键删除时级联清理关联记录。

### 6.5 assets：文件元数据表

| 字段 | 类型 | 说明 |
|-|-|-|
| id | TEXT | 主键 |
| r2_key | TEXT | 唯一 R2 对象 key |
| original_name | TEXT | 原始文件名 |
| mime_type | TEXT | 文件 MIME 类型 |
| size_bytes | INTEGER | 文件大小 |
| width | INTEGER | 可选图片宽度 |
| height | INTEGER | 可选图片高度 |
| created_at | TEXT | 上传时间 |

正文只保存图片 URL，不保存 Base64 或图片二进制数据。

**去重与扩展名：**补充 `content_hash`（SHA-256，唯一）用于去重，同一图片重复上传直接复用已有 R2 对象。R2 key 使用 `posts/YYYY/MM/<hash>.<ext>`，扩展名按文件头识别，不要固定写 `.webp`，因为第一版不做转码。上传先写 R2 再写 D1；D1 失败时尽力删除 R2 对象，并定期清理 30 天内未被引用的对象。删除前检查正文、封面和设置中的引用。

### 6.6 settings：网站设置表

| 字段 | 类型 | 说明 |
|-|-|-|
| key | TEXT | 设置项主键 |
| value | TEXT | JSON 或字符串值 |
| updated_at | TEXT | 更新时间 |

### 6.7 可选后续表

- `post_revisions`：文章历史版本和误删恢复。
- `comments`：评论与审核状态。
- `login_attempts`：自实现登录时的失败次数和限流。
- `redirects`：文章 slug 修改后的旧地址跳转。
